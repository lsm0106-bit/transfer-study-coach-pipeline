# 편입 학습 코치: 격리 테스트 스냅샷

이 저장소에는 개인 학습 데이터와 원본 시트 ID를 제외한 Google Apps Script 코드 및 매니페스트가 있습니다. 운영용 배포본이 아니며, 실제 학습 자료에 연결하지 마세요.

## 파일과 개인정보 보호

- `Code.gs`: 공개용으로 정리한 합성 테스트 스냅샷. `TEST_SPREADSHEET_ID`는 `REPLACE_WITH_TEST_SPREADSHEET_ID`로 대체했습니다. 파일의 SHA-256은 `96d2a1b54bb20d270e4bf040ba49de5f21c514035195985b0232447e0ecf48fe`입니다.
- `appsscript.json`: `spreadsheets.currentonly`만 선언합니다.
- 코드에는 `setupPipeline()`이 비활성화되어 있습니다. 테스트가 필요하면 실제 자료가 없는 새 합성 테스트 시트만 사용하세요. 기존 프로젝트나 학습 자료에 연결해 실행하지 마세요.

## 버전과 검증 한계

이 저장소의 `Code.gs`는 41,847자입니다. 별도 격리 테스트에서 실행된 최신 코드는 47,110자, SHA-256 `a949bc34ab6adc19335c8991efa6e82d1400a73c08a617607b372e3be72f1855`로, 이 저장소의 코드와 버전이 다릅니다. 따라서 해당 테스트 결과는 여기 게시된 코드의 통과 인증이 아닙니다.

별도 테스트 기록에서는 복구·날짜 경계 사례 5개와 편집기에서 겹친 동시 저장 2건이 통과했습니다. 메뉴 팝업은 `script.container.ui` 권한 부족으로 검증되지 않았습니다. 실제 학습 자료 연결과 운영 배포는 하지 않았습니다.

게시된 코드의 전체 정적 검토와 별도 격리 테스트 없이는 실사용 안전성을 주장하지 않습니다.
